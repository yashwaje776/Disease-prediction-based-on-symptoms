# 🩺 Disease Prediction Based on Symptoms

A Machine Learning-powered web application that predicts possible diseases based on symptoms entered by users. This project helps users get a preliminary understanding of potential health conditions and encourages timely medical consultation.

## 🌐 Live Demo

**Web Application:**
https://disease-prediction-based-on-symptoms-3kpq.onrender.com/

**Prediction API Endpoint:**
https://disease-prediction-based-on-symptoms-3kpq.onrender.com/predict

---

## 🚀 Features

* 🔍 Predict diseases based on user-provided symptoms
* 🤖 Machine Learning-based disease classification
* 🌐 REST API for disease prediction
* 📊 Trained on symptom-disease datasets
* ⚡ Fast and responsive predictions
* 📱 User-friendly web interface
* ☁️ Deployed on Render

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yashwaje776/disease-prediction-based-on-symptoms.git
cd disease-prediction-based-on-symptoms
```

### 2. Create a Virtual Environment

#### Linux / macOS

```bash
python -m venv venv
source venv/bin/activate
```

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

### Train the Model (Optional)

```bash
python train_model.py
```

### Start the Flask Server

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 🔌 API Usage

### Endpoint

```http
POST /predict
```

### Example Request

```json
{
  "symptoms": [
    "fever",
    "headache",
    "fatigue"
  ]
}
```

### Example Response

```json
{
  "predicted_disease": "Viral Infection"
}
```

### cURL Example

```bash
curl -X POST \
https://disease-prediction-based-on-symptoms-3kpq.onrender.com/predict \
-H "Content-Type: application/json" \
-d '{
  "symptoms": ["fever","headache","fatigue"]
}'
```

## 🧠 Machine Learning Model

The system uses supervised machine learning techniques to classify diseases based on symptoms.

Possible algorithms include:

* Decision Tree Classifier
* Random Forest Classifier
* Naive Bayes Classifier

The model is trained on labeled symptom-disease data to learn relationships between symptoms and diseases.
